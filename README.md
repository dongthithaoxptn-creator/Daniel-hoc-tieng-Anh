# Dino Hero

A personal English-learning game for one child. Open `index.html` through a web address (GitHub Pages or any static host).
The microphone only works on a secure `https://` address.

## Voice
The recordings in `voice/` were generated with [Piper](https://github.com/OHF-Voice/piper1-gpl) using the
`en_US-ljspeech-high` voice, which is trained on the public-domain LJ Speech dataset. They are not recordings of
any book or course. Words without a recording use the device's own voice.
